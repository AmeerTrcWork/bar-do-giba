# 🥟 Bar do Giba - Official Website
**Moema, São Paulo - SP**

Site oficial e interativo para o lendário boteco e templo dos pastéis artesanais em Moema, São Paulo.

---

## 🚀 Como Executar Localmente

```bash
# Iniciar o servidor local
npm start
```
O servidor estará rodando em `http://localhost:3000`.

---

## 🌐 Deploy no Railway

1. Conecte este repositório no **[Railway.app](https://railway.app)**.
2. O Railway detectará automaticamente o arquivo `package.json` e executará `npm start`.
3. Gere um domínio público em **Settings > Networking > Generate Domain**.
